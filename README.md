# Blockwright tutorial

Learn to make ANSI and IRC art with [Blockwright](https://git.pumpin.online/funkpower/blockwright), starting from nothing: what a cell is, how half blocks become pixels, how a shade ladder works, how to light a shape, and how to get a piece onto IRC inside the byte budget.

Published at <https://lrh.pumpin.online/blockwright/>.

## Layout

| Path | What |
|---|---|
| `lessons/` | One Markdown file per lesson, in reading order |
| `samples/<lesson>/` | The `.ans` files a lesson shows, step by step, and what renders them |
| `site/` | The built site, as deployed |
| `scripts/deploy` | Copies `site/` to the web root |

`PLAN.md` is the curriculum and how the site gets built.
