# Samples

One folder per tutorial, named as the tutorial (`03-pixels-with-half-blocks/`). In it: the `.ans` for each step (`step-01.ans`, `step-02.ans`, …, `final.ans`), the exercise's starting file (`try.ans`), and whatever made them (a `steps.json` for `blockwright-cli replay`, or a note describing the file). PNGs are build output, not tracked.
